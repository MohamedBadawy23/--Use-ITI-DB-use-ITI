# SQL Server Database Programming – ITI Assignments

A collection of SQL Server practical assignments focused on database programming, data manipulation, database objects, and relational database management.

## 📌 Project Overview

This repository contains practical SQL Server exercises covering advanced database concepts using different databases, including ITI, MyCompany, IKEA_Company, and RouteCompany.

The assignments demonstrate how to create and manage database objects, retrieve and manipulate data, enforce relationships, and organize database structures.

## 🛠️ Technologies Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL (Transact-SQL)

## 📚 Topics Covered

### 1. User-Defined Functions
- Scalar Functions
- Inline Table-Valued Functions
- Multi-Statement Table-Valued Functions
- Conditional Logic
- Date Formatting and Conversion
- Data Retrieval and Filtering

### 2. Views
- Creating and Altering Views
- Encrypted Views
- Schema-Bound Views
- Views with CHECK OPTION
- Aggregate Functions inside Views
- Managing Views across Different Schemas

### 3. Database Design and Relationships
- Creating Tables
- Primary Key Constraints
- Foreign Key Constraints
- Unique Constraints
- NOT NULL Constraints
- Referential Integrity

### 4. Data Manipulation Language (DML)
- INSERT
- UPDATE
- DELETE
- SELECT
- Testing Referential Integrity Rules

### 5. Database Schema Management
- Creating Schemas
- Transferring Tables Between Schemas
- Adding and Dropping Columns
- Organizing Database Objects

### 6. Practical SQL Operations
- Working with Multiple Databases
- Joining Related Tables
- Using Aggregate Functions
- Handling NULL Values
- Working with Date and String Functions
- Managing Employee and Department Data
